Gutenberg Times’ Weekend Edition 376 surveys the WordPress 7.2 cycle, Gutenberg and WooCommerce changes, contributor requirements, Playground, WebMCP, and community projects. It reports that 7.2 planning is underway, while WordPress 7.1.1 RC1 is scheduled as a bug-fix release.

The article says WordPress development trunk now requires Node.js 24.18.0 and npm 11.16.0. It also describes WooCommerce 11.1’s core variation galleries and a filter controlling block registration during API requests.

Playground’s WebMCP integration reportedly exposes 16 tools for agents, including site management, PHP execution, navigation, and file operations. WebMCP remains a W3C Community Group draft, and the roundup includes proposals and scheduled work whose final status is not established here.
