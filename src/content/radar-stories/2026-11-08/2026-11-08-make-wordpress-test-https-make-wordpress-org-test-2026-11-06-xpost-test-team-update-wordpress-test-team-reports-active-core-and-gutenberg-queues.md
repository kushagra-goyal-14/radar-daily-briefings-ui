The WordPress Test Team’s November 6 update reports active testing queues for WordPress Core and Gutenberg. It lists 117 Core issues needing reproduction, 137 needing patch testing, eight Gutenberg issues needing reproduction, and one needing patch testing.

The report also records changes from the prior two weeks, including a decrease in Core patch-testing items and Gutenberg reproduction items increasing by one. It directs contributors to recurring Patch Testing Sessions held every second and fourth Thursday at 3:00 pm UTC in #core-test.

The update is useful for selecting current testing work, but it does not describe testing methodology or the individual issues behind these totals.
