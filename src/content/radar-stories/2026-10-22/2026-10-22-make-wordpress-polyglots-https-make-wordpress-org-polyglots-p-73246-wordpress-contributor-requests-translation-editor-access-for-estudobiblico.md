A contributor has requested Project Translation Editor access for the EstudoBiblico Bíblia Digital plugin’s Brazilian Portuguese locale. The request concerns reviewing and approving an imported translation.

The contributor reports that all 407 strings were imported. They explain that the plugin’s source strings were Portuguese until version 1.2.0 and are now English, and say the imported Portuguese wording already runs in production on estudobiblico.org.

The document describes the requested role as able to approve translations for a specific project. It does not state whether access was granted, so the request remains a proposed localization workflow change.
