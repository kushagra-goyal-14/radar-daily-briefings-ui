WordPress 7.2 Beta 1 is available for download and testing. The release is experimental and the official guidance says it should be used only in test environments, not on production or mission-critical websites.

The beta adds responsive design controls, improved Global Styles tools, text shadows, Notes changes, client-side media processing, a Secrets API, expanded Abilities API capabilities, and Interactivity API enhancements. Administration changes include individual asset loading and prefetching.

Plugin, theme, and site engineers can evaluate compatibility through the Beta Tester plugin, WP-CLI, direct downloads, or WordPress Playground. The supplied documents disagree on the final release date, and no performance measurements are provided.
