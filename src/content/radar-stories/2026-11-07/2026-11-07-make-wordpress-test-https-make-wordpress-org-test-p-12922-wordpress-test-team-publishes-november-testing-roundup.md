The WordPress Test Team’s November 6 roundup presents current testing opportunities across WordPress Core and Gutenberg. It includes patch-testing and bug-reproduction work, contributor guidance, and upcoming Test Team meetings.

The post reports that the Test Handbook review process concluded with a merge and that the handbook is officially synced. It notes that some bugs and presentation issues may still need fixing. The roundup also lists 11 Core patch-testing tickets, 117 bug-reproduction tickets, and one Gutenberg patch-testing ticket.

This is an in-progress coordination update rather than a software release or completed testing report. Contributors can use the listed tickets and schedules to select work.
