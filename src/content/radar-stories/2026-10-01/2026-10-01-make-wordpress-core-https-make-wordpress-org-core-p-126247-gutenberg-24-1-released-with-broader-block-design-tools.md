Gutenberg 24.1 has been released and is available for download. The release focuses on consistent design tools across core blocks and includes about 140 related pull requests.

New and expanded capabilities include background, gradient, shadow, border, color, typography, and text-column controls. Text-shadow is supported through theme.json and Global Styles, while the Block API adds a public viewport-state API for custom controls. Cover and Media & Text add media selection in their inspector panels.

The release also includes pattern search and category filtering, unavailable alignment states, icon redraw completion, component changes, and tooling updates. The supplied post does not provide detailed migration guidance for every API or block change.
