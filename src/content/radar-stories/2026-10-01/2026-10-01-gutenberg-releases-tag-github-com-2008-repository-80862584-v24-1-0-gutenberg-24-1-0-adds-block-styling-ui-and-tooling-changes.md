WordPress Gutenberg 24.1.0 was released on September 30, 2026. The release combines new editor capabilities, block-library enhancements, component changes, bug fixes, and developer-tooling updates.

It adds CheckboxGroup, RadioGroup, and Switch primitives; expands block support for gradients, images, shadows, borders, colors, spacing, and typography; and introduces viewport-state support in the Block API. Several components are deprecated, while testing work continues the migration toward Vitest Browser Mode.
