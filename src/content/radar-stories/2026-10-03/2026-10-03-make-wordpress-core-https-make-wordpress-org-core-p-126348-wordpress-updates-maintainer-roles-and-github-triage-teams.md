WordPress has updated its Core Component Maintainer and Core Bug Gardener lists and added GitHub teams to the wordpress-develop repository. The changes clarify responsibility for project areas and are already in effect.

The new Gutenberg, WordPress Core Component Maintainers, and WordPress Core Bug Gardeners teams have triage-level access. Members can request code reviews, assign labels, and help manage pull requests. The previous Core PR Triage team was considered unnecessary and folded into the bug gardeners group.

Contributors can volunteer for maintainer or bug gardener roles, but must connect their GitHub and WordPress.org accounts. Team invitations must be accepted within seven days, and some contributors may have been missed during import.
