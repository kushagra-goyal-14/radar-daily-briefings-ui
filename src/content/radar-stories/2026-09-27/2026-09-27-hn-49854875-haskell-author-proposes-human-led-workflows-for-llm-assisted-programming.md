A Haskell community post presents a human-led approach to LLM-assisted programming. The author argues that developers should continue writing core code while using agents for surrounding work.

The workflow assigns LLMs tasks such as converting discussions into todos, organizing research, identifying code locations and pitfalls, handling routine refactors, and reviewing plans or generated artifacts. The author recommends independently checking research, preserving tangible task lists, and keeping humans responsible for decisions and code.

The post is practical guidance rather than a measured study. Its reported productivity improvement is informal, and the evidence does not establish broader effects.
