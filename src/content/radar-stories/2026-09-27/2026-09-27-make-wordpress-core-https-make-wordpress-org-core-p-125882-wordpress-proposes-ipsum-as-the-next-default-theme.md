WordPress has opened Ipsum for testing as a proposed next default theme, planned for bundling with WordPress 7.2. The project is seeking feedback before the release, and formal development review remains ahead.

Ipsum is a minimal blank-canvas blog theme built around the blogging experience. Its design includes style variations, editor-inspired visual details, and combinations described as meeting WCAG 2.1 AA. The project is also moving away from year-based default-theme names.

Developers can test the current build and report missing or broken behavior. The proposal is not yet a confirmed release, and Mētis remains separate from the 7.2 default theme.
