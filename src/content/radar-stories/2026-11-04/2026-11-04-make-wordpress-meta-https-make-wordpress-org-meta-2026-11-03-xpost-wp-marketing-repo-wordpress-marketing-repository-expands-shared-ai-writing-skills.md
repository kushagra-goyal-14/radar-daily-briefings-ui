The WordPress marketing repository is expanding shared AI writing skills for news, event recaps, Showcase entries, and social content. The official post says these skills are already used in automated workflows and remain incrementally improved.

The skills are based on the WordPress Brand Writing Style Guide. The marketing handbook now syncs from GitHub, enabling contributors and agents to submit pull requests. The post also describes an ongoing migration from Zapier to n8n and an agent that monitors communications for issues.

The work is in progress: a monitoring dashboard is not yet documented, and the post supplies no architecture or performance measurements. The repository also has 60 open non-amplification, non-Showcase issues, many considered outdated.
