The WordPress marketing repository now provides AI-assisted skills for news writing, event recaps, Showcase entries, and social content. The post says these skills are already used in automated workflows and have been incrementally improved over several years.

The skills are based on the WordPress Brand Writing Style Guide. The marketing handbook now synchronizes from GitHub, enabling contributors and agents to submit pull requests for updates.

The project is also migrating workflows from Zapier to n8n and using an agent to monitor communications for issues. A dashboard is planned but not yet documented, and the post reports 60 open issues in selected categories.
