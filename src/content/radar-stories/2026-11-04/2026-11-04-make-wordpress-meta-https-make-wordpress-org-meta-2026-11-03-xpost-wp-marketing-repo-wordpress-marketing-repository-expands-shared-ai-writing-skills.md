The WordPress Marketing Repository has added AI-assisted skills for writing WordPress.org news, event recaps, Showcase entries, and social content. The post presents the work as ongoing and invites pull requests for documentation updates.

According to the post, the skills use an adapted WordPress Brand Writing Style Guide and already support automated workflows. The marketing handbook now syncs from GitHub, while additional workflows are expected to move from Zapier to n8n.

The team also plans a documented communications-monitoring dashboard and is cleaning up 60 open non-amplification, non-showcase issues. The supplied material does not explain implementation details or demonstrate broader impact.
