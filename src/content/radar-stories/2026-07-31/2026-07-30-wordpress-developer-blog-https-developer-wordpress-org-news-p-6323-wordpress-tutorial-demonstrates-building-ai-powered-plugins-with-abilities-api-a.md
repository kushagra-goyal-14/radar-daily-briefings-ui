WordPress.org has published a step-by-step tutorial for building an AI-powered plugin that integrates three WordPress 7.0+ Core AI features. The work is complete and released.

The tutorial walks developers through building Photo to Post, a plugin that accepts an image URL, uses a vision-capable AI model to describe the image, generates a blog post title and content from that description, and creates a draft post with the image as the featured image. The plugin demonstrates three key WordPress AI building blocks: the Abilities API for registering discoverable functionality, the WordPress AI Client for provider-agnostic access to OpenAI, Anthropic, Google, and other AI providers, and the MCP Adapter for exposing abilities to autonomous AI agents.
