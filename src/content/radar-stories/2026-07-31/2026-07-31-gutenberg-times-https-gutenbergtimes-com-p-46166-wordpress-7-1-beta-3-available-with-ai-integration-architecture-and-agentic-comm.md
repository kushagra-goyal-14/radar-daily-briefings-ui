WordPress 7.1 Beta 3 is now available for testing with several component updates including text shadow support in Global Styles, editable blocks within the Custom HTML block, and SVG icon registration improvements. React 19 support has been deferred beyond 7.1. Unicode email validation was deferred over security concerns.

The WordPress AI Client architecture, introduced in WordPress 7.0, unifies AI provider integration through three layers—Connectors, AI Client, and Providers—replacing bundled SDKs with a unified wp_ai_client_prompt() function. The AI 1.2.0 plugin adds a Suggest Reply experiment for comment moderation and bulk content summary generation. The WordPress Playground UI is open for community testing before its official launch, including Blueprint workflows and developer tools like Files and Logs.
