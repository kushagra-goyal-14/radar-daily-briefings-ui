The WordPress Core development team has scheduled a dev chat for Tuesday, July 28, 2026, at 15:00 UTC in the Make WordPress Slack core channel. The meeting will focus on upcoming releases and include an open-floor section for contributor discussion.

WordPress 7.1 Beta 3 was released on July 22, 2026. Beta 4 is scheduled for July 29, 2026, at 15:00 UTC. Dev Chat has been moved to Tuesdays at 15:00 UTC for the duration of the 7.1 release cycle.

New dev notes cover client-side media processing, text shadow support in global styles, media library infinite scroll enabled by default, editable blocks inside the Custom HTML block, SVG icon registration and rendering, minimum-width block support, and background gradient block support.
