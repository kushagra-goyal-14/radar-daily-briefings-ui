The WordPress core performance team held a coordination chat on July 28, 2026, discussing infrastructure improvements, security updates, and block refinements.

Weston Ruter highlighted an important security release for wpcs (WordPress Coding Standards) version 3.4.1. The update has been applied to the Performance repository, and the summary recommends that maintainers of other repositories using older versions update immediately. The specific vulnerability details are not described in this summary.

Mukesh27 reported progress on accurate sizing for the Gallery block over several weeks, with a pull request soon ready for review. Separately, ticket #65634 proposes a minor development environment improvement to make performance tests more reflective of actual conditions, with a patch awaiting review.
