The WordPress Accessibility Team has posted its agenda for a bi-weekly meeting scheduled for Thursday, July 30, 2026 at 15:00 UTC.

The agenda lists WordPress 7.0.2 as released and WordPress 7.1 Beta 3 as available for download and testing. WordPress 7.1 Beta 4 was scheduled for release on July 29. Working group updates cover WordPress Core and Block Editor accessibility, an accessibility-ready program, and documentation about web accessibility.

Andrea Fercia requested discussion or an update on recent changes to enable Media Library infinite scrolling, a topic flagged for accessibility review.
