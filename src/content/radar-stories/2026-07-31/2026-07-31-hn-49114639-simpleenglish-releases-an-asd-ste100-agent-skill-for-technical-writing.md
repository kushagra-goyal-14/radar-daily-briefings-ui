The SimpleEnglish project provides an installable agent skill that applies paraphrased ASD-STE100 Simplified Technical English rules to technical writing. The repository includes installation commands and prompt-based alternatives for environments without skill support.

The skill defines 53 numbered rules and adaptations for error messages, runbooks, incident reports, release notes, agent instructions, and translation preparation. It emphasizes short sentences, active voice, simple tenses, explicit conditions, and one instruction per sentence.

The project reports 72.9% fewer STE violations per 100 words across 96 generations, with output tokens decreasing on all six evaluated models. These results are project-reported, and the skill does not provide STE certification; the repository is unofficial and unaffiliated with ASD or STEMG.
