WordPress Contributor Toolkit 2.0.0 has been released with a redesigned interface based on the WordPress Design System. It supports Core and Gutenberg contribution workflows and ships in ten languages.

The release adds centralized settings for themes, language, server behavior, site PHP versions, debug flags, and account details. It also presents changed files as a tree, supports per-file reverts, preserves Trac details between launches, and opens the relevant database in Adminer for randomized SQLite storage or custom DB_PATH values.

Version 2.0 is about 350 MB smaller once installed after removing unused components. The supplied material documents features and packaging changes, but not independent impact measurements.
