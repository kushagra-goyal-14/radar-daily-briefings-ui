Claude Code version 2.1.277 adds support for AGENTS.md. When a folder does not contain CLAUDE.md, Claude Code will check for and use AGENTS.md, according to the quoted statement from Thariq Shihipar.

The support is built on Claude Code mods, described as an upcoming customization mechanism for the Claude Code harness. The feature includes a built-in mod, while users will be able to build custom project-instruction versions.

This gives teams a documented fallback filename for repository-level instructions in Claude Code. The supplied evidence does not explain precedence when both files exist or provide implementation details for custom mods.
