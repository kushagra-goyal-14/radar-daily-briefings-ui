The WordPress 7.2 roadmap targets an early December 2026 release and proposes work across the block editor, accessibility, security, media, styling, and AI integrations. The post explicitly says the listed efforts may not all reach the final release.

Security plans include hardening Application Passwords, a proposed Secrets API for credential storage, and initial work on sudo mode, which would require re-authentication for highly privileged actions. The roadmap also describes an extensible Site Editor foundation for plugin-registered screens and settings.

AI-related work remains centered in the AI plugin and includes MCP, WebMCP, agent identity, embeddings, and streaming responses. Engineers should treat these as roadmap items rather than committed capabilities.
