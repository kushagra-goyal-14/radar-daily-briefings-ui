WordPress 7.1 is complete, and the WordPress Test Team has published a recognition post for its testing contributors. It reports 337 Core Trac tickets evaluated, 84 participants, 50 new contributors, 75 patch testers, and 21 bug-reproduction contributors.

The post explains that testing can use WordPress Playground, the WordPress Contributor Toolkit, a local Docker environment, or Gutenberg-specific workflows. Contributors can reproduce issues, apply patches, record environment details, and help triage tickets through documented templates and keywords.

The figures cover Core Trac tickets for the 7.1 milestone only; testing performed directly in Gutenberg's GitHub repository is excluded. The post also invites participation in the WordPress 7.2 cycle.
