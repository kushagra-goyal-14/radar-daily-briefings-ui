The Core Security Initiative reports that WordPress has accelerated its security operations. It shipped four security releases in 41 days, seven since mid-July, and says more than 50 Critical or High vulnerabilities were closed across branches as far back as 4.7.

The initiative describes set release squads, two-wave shipping, and automation covering 73% of 109 release steps. An AI-powered system triages HackerOne reports, securely reproduces them, and recommends validity and severity; security researchers retain the final decision.

The same tooling is being redirected toward proactive core vulnerability hunting using open-weight models and purpose-built harnesses. The update reports a backlog reduction from 359 untriaged reports to double digits, but supplies no independent validation of these metrics or AI accuracy.
