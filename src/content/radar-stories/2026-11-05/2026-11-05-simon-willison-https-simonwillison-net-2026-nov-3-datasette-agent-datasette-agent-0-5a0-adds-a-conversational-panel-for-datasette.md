datasette-agent 0.5a0 has been released as an LLM-powered agent for Datasette. Its most notable addition is a panel that places agent chat alongside Datasette pages, including table and query views.

The panel provides a conversational workflow next to the database-backed application. Simon Willison says that, when combined with datasette-apps, users can prompt an application into existence and then modify it from the adjacent chat.

Engineers can try the hosted service at agent.datasette.io using GitHub sign-in. The release description does not provide architecture, deployment, configuration, or performance details, so the documented workflow is the main available evidence.
