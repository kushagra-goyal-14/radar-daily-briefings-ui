WordPress Hosting contributors are invited to join WordCamp Canada 2026 Contributor Day on November 4, in Vancouver or remotely. The planned work covers distributed testing, Test Runner improvements, and Hosting Handbook updates.

The team maintains PHPUnit-based software that lets hosts test unreleased WordPress updates and report conflicts or errors. Proposed improvements include multi-environment testing, testing multiple PHP versions in one environment, and documentation for matrix testing.

Contributors need WordPress.org, Slack, and GitHub accounts, plus Git and an editor. Testing-software changes must be validated on a hosting platform, while pull requests require two approvals and an up-to-date base branch.
