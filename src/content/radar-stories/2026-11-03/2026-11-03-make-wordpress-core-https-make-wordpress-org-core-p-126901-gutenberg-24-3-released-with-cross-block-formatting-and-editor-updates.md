Gutenberg 24.3 has been released and is available for download. The release adds rich-text formatting across selections spanning multiple blocks, emoji reactions for notes, a redesigned Media inserter, and clearer save and autosave failure handling.

The Media inserter now uses a DataViews grid, while non-image and non-video files receive previews. Save failures offer copyable details, and autosave failures can show HTTP status, retry timing, and a notice that clears after a later successful save. Developers also receive server-side Core entity actions and fields and Interactivity API fixes.

The release includes the security fixes from WordPress 7.1.4, but the supplied document does not describe them. Engineers should review the detailed changelog for affected integrations and behavior changes.
