WordPress reports that work is largely complete to make the accessibility-ready tag conditional in the theme directory, with additional setup still required. Implementation of updated tag listings will therefore be briefly delayed.

The change will not delist themes that have not yet met accessibility-ready requirements, and adding the tag will not delay theme approval. Instead, the tag will function as an application for inclusion in the listings.

WordPress says the tag’s trust value will increase because it can be removed from themes that do not meet accessibility guidelines. The supplied post does not specify the implementation date or detailed review procedure.
