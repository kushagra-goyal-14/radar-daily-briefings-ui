WordPress Community Events organizers can request sponsor vetting directly from a sponsor record in the event dashboard. The workflow is documented as available and is intended to replace email or spreadsheet submissions.

Organizers enter the sponsor’s required contact and address details, save the record, and use the Sponsor Vetting panel to submit the request. The dashboard displays statuses including Not Requested, Waiting on Sponsor, and Approved.

After approval, organizers can create an invoice for approval or send it directly when an event handles funds locally. The document describes the user workflow but does not provide implementation details, review criteria, or expected processing times.
