An opinion essay argues that coding agents make open-source devtools substantially easier to personalize. It proposes modifying software from source and automatically rebasing local changes onto upstream releases, but does not report a formal release or merged change.

The article describes Shelley as an agent that can incorporate skills and source changes, and presents meat.dev as a tool that summarizes diffs with LLMs before review. A single prompt reportedly integrated meat processing into Shelley’s commit workflow.

The author argues that source access can replace many configuration and plugin systems. The supplied evidence is anecdotal, with no reproducible measurements or systematic assessment of maintenance constraints.
