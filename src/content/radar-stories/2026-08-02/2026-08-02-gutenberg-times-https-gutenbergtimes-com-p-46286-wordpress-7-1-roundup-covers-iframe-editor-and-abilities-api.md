Gutenberg Times’ Weekend Edition 371 surveys WordPress 7.1 Beta 4, Gutenberg 23.6, the forced iframed post editor, the Abilities API, Playground, and developer tooling. WordPress 7.1 remains in progress rather than final release.

The roundup highlights iframe migration work for blocks that access global browser objects or rely on editor styling. It also describes Abilities API contracts, WP-CLI inspection, REST execution, block bindings, and Playground site-management workflows.

For engineers, the key task is compatibility testing before the iframe editor arrives and evaluating the documented API boundaries. The source also flags experimental tooling and unresolved or unsupported capabilities, including theme.json overwrites without backups and limited Playground API availability.
