A WordPress contributor has requested Project Translation Editor access for the Hueman theme in the Gujarati (gu) language. The document describes the request as part of ongoing Gujarati translation work.

A Project Translation Editor can validate and approve strings for a specific project and locale. The contributor says Gujarati editor availability is limited, which may slow localization progress for the theme.

The document does not report that access has been granted or that an editor has been appointed. It is therefore a proposed community request, relevant mainly to contributors working on Gujarati WordPress translations.
