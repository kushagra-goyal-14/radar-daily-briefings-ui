The author of Mowl — E-mail Marketing has requested Project Translation Editor access for the hu_HU locale. The request is intended to support approval and maintenance of the plugin’s Hungarian translations.

The author says 247 Stable project strings and 138 Stable Readme strings are awaiting review. The request names the WordPress.org account @molnaradam and links to the plugin’s translation projects.

This is an access request, not confirmation of an approved editor role. Its practical significance is limited to maintaining Mowl’s Hungarian localization; the supplied document provides no broader technical implementation details.
