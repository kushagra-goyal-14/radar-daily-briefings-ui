The Capi Agent author has requested Project Translation Editor access for the plugin’s Arabic and Turkish translations. The request is addressed to the WordPress Polyglots community and remains a proposal.

The post reports that both locale translations are complete, with 62 of 62 strings translated in Arabic and Turkish. It also says the translations have already been imported as waiting suggestions.

Granting PTE access would allow approval of the plugin’s translations, but the supplied evidence does not say whether access was granted. The request contains no implementation or broader operational changes.
