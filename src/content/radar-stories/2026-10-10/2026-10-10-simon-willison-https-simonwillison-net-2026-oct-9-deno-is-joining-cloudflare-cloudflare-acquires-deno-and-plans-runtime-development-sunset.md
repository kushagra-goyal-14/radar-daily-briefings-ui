Cloudflare is acquiring Deno outright and plans to build on celld to support self-hosted workerd for applications using the Workers programming model. The acquisition is underway, while Deno remains supported for a stated one-year period.

Cloudflare says monthly releases during that year will contain bug fixes and security updates, after which it will end development of the Deno runtime. Deno will remain open source. Ryan Dahl describes celld as using object storage for coordination and persistence and as a different model for server development.

Deno users should account for the stated support horizon in platform planning. The supplied material does not include a detailed transition or migration plan.
