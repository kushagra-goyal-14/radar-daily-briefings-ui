The WordPress Polyglots team has updated its list of glossaries and style guides organized by locale. The post describes the change as a completed update to the directory format.

The previous version used an HTML table that was difficult to maintain. The new format is intended to make updates easier, support additional information such as links to style guides for agents, and provide direct anchors for individual locales.

Locale contributors are asked to verify coverage and link accuracy. The post also suggests moving hard-to-reach documents to locale team subsites, but it provides little implementation detail beyond the documentation change.
