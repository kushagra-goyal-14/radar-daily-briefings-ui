A WordPress proposal outlines minor updates to the Core CSS Coding Standards needed before integrating Stylelint into Core and continuous integration. It asks for comments over one week and suggests proceeding afterward if no significant objections arise.

The proposed rules simplify blank-line requirements to one blank line between sections and blocks. They also advise avoiding the `order` property and `*-reverse` values when they alter reading or interaction order, reflecting accessibility concerns described in the proposal.

The document also records smaller wording and exception changes. The update remains a proposal, while broader standards revisions are deferred until Stylelint provides relevant data.
