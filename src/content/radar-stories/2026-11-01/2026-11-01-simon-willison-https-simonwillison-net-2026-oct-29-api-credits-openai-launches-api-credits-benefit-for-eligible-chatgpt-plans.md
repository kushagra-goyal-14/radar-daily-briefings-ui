Simon Willison reports that OpenAI has launched an API-credit benefit for eligible ChatGPT subscriptions priced at $100, $200, or $500 per month. The reported credit amount matches the subscription price.

The credits can be applied to one of the subscriber’s API organizations, according to the post. The report describes the benefit as closely following Anthropic’s earlier subscription-credit announcement.

This could affect subscription comparisons and give developers additional budget for API projects or public demonstrations. The supplied evidence does not specify eligible plan names, expiration terms, usage restrictions, or other conditions.
