The author of Prevent Browser Caching has submitted translation suggestions for the plugin’s UI and current readme across 10 WordPress locales. The post asks Polyglots teams to review and approve them where appropriate.

The submission covers 86 UI strings and 95 readme strings. The author reports 181 strings waiting in Stable and Stable Readme for each locale and links to the translate.wordpress.org project.

This is a proposed localization review task, not a plugin release or code change. The author notes they do not speak the listed languages, so approval depends on the relevant locale teams’ review.
