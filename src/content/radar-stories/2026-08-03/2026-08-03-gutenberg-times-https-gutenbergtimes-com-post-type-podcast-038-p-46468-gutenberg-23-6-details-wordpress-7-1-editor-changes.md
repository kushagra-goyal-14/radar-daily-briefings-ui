The Gutenberg Changelog episode reports the Gutenberg 23.6 release and discusses WordPress 7.1 at Beta 4. Gutenberg 23.6 is described as the final feature release contributing features to WordPress 7.1.

Highlighted changes include configurable tablet and mobile viewports in theme.json, responsive text alignment, grid autofit, SVG icon collections, editable blocks inside Custom HTML blocks, and expanded collaboration notes. The post editor is also moving into an iframe, following the site, template, and pattern editors.

The iframe transition is intended to isolate editor designs from the surrounding admin page, but older blocks and collections may exhibit compatibility quirks. Developers are encouraged to test WordPress 7.1 and review the related guidance.
