WordPress 7.2 Beta 1 is available for download and testing, marking the next major release’s testing phase. The roundup says the final release is planned for December 8 and advises against using the beta in production.

The beta introduces Notes displayed in a margin beside the editor canvas, emoji reactions, text shadows, form-element styling, a Secrets API for plugins, and client-side media processing in the Media Library. Notes suggestion mode was deferred to 7.3.

Engineers can use the WordPress Playground instance or a test site to evaluate compatibility. The supplied evidence is a broad roundup and does not include detailed API compatibility guidance.
