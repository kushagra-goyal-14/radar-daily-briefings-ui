The WordPress Feature Notifications project reports a maintenance-focused week with 24 merged pull requests, including 23 Dependabot updates. Sixteen new contributor pull requests were opened and remain under review.

Active work includes GET, POST, and DELETE notification REST API endpoints, schema v2 tables and documentation, user-scoped repositories, UTC date handling, UI changes, and fixes to PHP, CSS, documentation, and package-lint scripts. The README now points developers to the demo plugin.

The update describes incremental project progress rather than a release. Seventeen stale Dependabot pull requests were closed without merging, and the supplied evidence does not describe deployment status or implementation details.
