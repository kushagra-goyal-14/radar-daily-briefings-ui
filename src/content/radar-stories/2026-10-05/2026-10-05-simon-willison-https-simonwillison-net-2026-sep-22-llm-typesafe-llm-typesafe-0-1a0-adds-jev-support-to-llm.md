Simon Willison announced llm-typesafe 0.1a0, an LLM plugin that adds support for TypeSafe AI’s Jev model. The document provides installation and API-key setup instructions.

The plugin is used through the LLM command-line tool. Examples show yes/no prompts returning structured `noul` output, choice questions using JSON criteria, and scoring questions using ordered reproducibility criteria.

This gives engineers a documented way to test structured Jev classifications from shell workflows. The supplied material does not describe the plugin’s architecture, benchmarks, or implementation internals, and access requires a TypeSafe AI API key.
