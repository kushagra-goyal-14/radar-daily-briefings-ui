WordPress has proposed making agent connectivity native, targeting broader core integration for WordPress 7.3 while using the 7.2 cycle to establish foundations. The proposal requests contributors and focus leads for the work.

The plan coordinates four areas: continued MCP Adapter development, baseline site-management Abilities, OAuth flows for secure authorization, and an end-to-end experience covering discovery, access, tasks, and permission management. It also identifies the Secrets API as relevant to secure token handling.

The proposal emphasizes security review, testing, architectural coordination, and early Core Committer involvement. No implementation is described as merged, and inclusion in core remains dependent on readiness, security, and normal review processes.
