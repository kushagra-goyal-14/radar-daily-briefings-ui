Wordfence 9.1.0 is now available as a release for WordPress security deployments. It adds a Security News Widget that brings security alerts and research to the WordPress dashboard.

The release also includes faster firewall rule updates, sharper request parsing, Live Traffic logging for application-password and REST API login failures, and configurable thresholds for attack alerts.

These changes give site operators additional monitoring and alerting controls alongside defensive-maintenance updates. The supplied release description does not provide benchmarks, architecture details, compatibility constraints, or configuration guidance, so engineers will need to assess those factors in their own deployments.
