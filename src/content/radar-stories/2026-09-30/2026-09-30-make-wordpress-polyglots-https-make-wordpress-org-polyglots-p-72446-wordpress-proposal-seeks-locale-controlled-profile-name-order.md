A WordPress Polyglots proposal seeks input on supporting locales where names are conventionally entered family name first. The document describes the current profile screen as fixed to First Name before Last Name and asks affected teams to report local practices and workarounds.

Its proposed first step is locale-controlled ordering of the profile fields through a translatable string and filter. The meanings of first_name and last_name would remain unchanged, while broader settings, per-user overrides, and contextual formatting would be deferred.

The proposal references long-running Core tickets and says no implementation has been merged. Evidence is limited because the response count is small and further locale confirmation is requested.
