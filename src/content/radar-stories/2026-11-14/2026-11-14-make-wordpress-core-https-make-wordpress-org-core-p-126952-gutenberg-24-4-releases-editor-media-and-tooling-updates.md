Gutenberg 24.4 has been released and is available for download. The WordPress editor update adds Notes search, status filtering, reactions, broader content-only editing, Global Styles override details, and browser-backup protection for draft content.

The experimental media editor now shows PDF previews, file type, and size. Developers also get an experimental wp-env runtime using locally installed PHP and SQLite, plus changes involving PHPStan, Storybook, Vite, and the Rolldown build pipeline.

The release includes many component, accessibility, performance, and block fixes. Engineers should distinguish the explicitly experimental features from the released editor changes, and note that the supplied changelog is truncated.
