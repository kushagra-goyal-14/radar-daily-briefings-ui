WordPress has introduced Mētis as a flagship theme for creators working across multiple forms. The project continues independently from the next default-theme direction, and its current build remains in development.

Built in the Site Editor, Mētis includes six starter sites, everyday templates, fifty section patterns, six whole-site style variations, and nine bundled open-source type families. Its palettes include dark-mode behavior and day/night color pairs that respond to device settings.

The current build reflects design work, with formal development review still ahead. Engineers and site builders can use the announcement as a reference for current WordPress theme capabilities, while treating the feature set as subject to review.
