WordPress 7.2 Beta 5 is available, with RC1 scheduled for November 17, 2026, and the final release planned for December 8. The roundup summarizes changes that plugin, theme, and hosting developers should test before release.

The new Secrets API encrypts credentials at rest, retains a previous version for rotation, and supports alternate storage through a secrets.php drop-in. Other changes include inline SVG admin icons, random content URLs, unbundled admin assets with prefetching, and new Interactivity API features.

The update also covers React 19 in Gutenberg, server-side entity fields and actions, theme.json input states, and Playground site cloning through Reprint. WordPress 7.2 remains in beta, and compatibility behavior requires testing.
